# 🧪 Parabank Automation and Manual Testing Project

An end-to-end QA testing project for the Parabank application including:

- ✅ Manual Testing (Excel documentation)
- 🔗 API Testing (Postman)
- 🤖 UI Automation Testing (Selenium, TestNG, Maven)

---

## 📁 Project Structure

```
manual-testing/           # Excel-based test cases and bug reports  
postman-api-testing/      # Postman collection + environment setup  
ui-automation/            # Java Selenium project with TestNG and Maven  
docs/                     # Project plan, tools used, and visuals  
reports/                  # Exported test execution reports  
```

---

## 🚀 How to Run UI Automation Tests

1. **Clone the repository**
   ```bash
   git clone <your-repo-link>
   cd ui-automation
   ```

2. **Make sure the following are installed:**
   - Java JDK 8+
   - Maven
   - ChromeDriver (or any browser driver)
   - TestNG

3. **Run the tests**
   ```bash
   mvn clean test
   ```

📂 Results will be available in the `test-output/` folder.

---

## 🧰 Tools Used

- **Manual Testing**: Excel, JIRA  
- **API Testing**: Postman  
- **UI Testing**: Selenium WebDriver, TestNG, Maven  
- **Reports**: TestNG HTML Reports
